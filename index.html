About this site

Served by GitHub Pages from the orphan gh-pages branch of malard/xbmc. That branch shares no history with master or with any feature branch, so a document published here can never appear in a pull request diff.

Every document is a single self-contained file. Nothing here is a Team Kodi publication.

Independently written. Not affiliated with Team Kodi.
