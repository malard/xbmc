Moving files without losing the library

Plainly

Rename a show's folder and Kodi cannot follow it. You delete the show and rescan, and the watched history, resume points and ratings go with it. Nothing in Kodi can move a library entry to a new path — not the API, not the database, not the interface.

Substance

  • No Set*Details method takes a path — all 32 checked.
  • No SQL anywhere rewrites path.strPath; the primitive does not exist.
  • Paths are also copied into movie, episode, musicvideo and art.
  • Two components. The database is the larger half.

01The gap

A folder rename is a prefix change, and there is no way to tell Kodi one happened.

Remove and rescan is the only route. It discards playcount, last played, resume points, date added, user rating, tags and art overrides, and issues fresh ids — to correct a name. The same holds for a movie, an album, or a whole source when a NAS is renamed. Path substitution in advancedsettings.xml remaps at runtime; it never repairs the database.

02The database

Relocation is a prefix rewrite, and cheap, because nothing worth keeping lives on a path row.

Playcount, resume and every id hang off the file row, which a path change does not touch, so one rewrite carries a whole show with it. The cost is that a path is stored in four places, not one.

A RelocatePath on CVideoDatabase and CMusicDatabase: transactional, clearing the path hash so the next scan is honest. Both stand up against a real sqlite schema under test. No new columns, so no migration.

03The API

One method, shaped around the path rather than the item.

An item-shaped call would have to derive the same prefix rewrite, and could not express a show's season subdirectories without assuming a layout. It also covers the whole-source move for free. A relocate per media type would repeat the mistake v14 just undid by folding four Refresh methods into one.

The destination must sit under an existing source, the check Scan already performs. Additive, so nothing to migrate.

Non-goals
  • Editing sources.xml. A source definition is not the library's to move.
  • Renaming a file rather than a directory. Movies with versions hold several file rows.
  • Moving anything on disk. Kodi is told what happened; it does not do it.
