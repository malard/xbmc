Plainly

The version numbers Kodi 22 presents to add-ons, skins and JSON-RPC clients, and the point in the cycle after which each can no longer change.

Substance

  • Breaking changes close at Beta 1, additive changes at RC1. Patch stays open.
  • Compatibility floors are fixed from Beta 1.
  • ADDON_API is determined by the cut.

Of the twenty binary add-on APIs, two moved after the Beta 1 cut: Game to 8.x and VideoCodec to 2.2.x. ADDON_INSTANCE_VERSION_GAME_MIN moved with it, so a game client built against Beta 1 must be rebuilt. The other eighteen are unchanged since Beta 1.

A floor — _MIN in versions.h, backwards-compatibility abi in an addon.xml — is what a compiled add-on is tested against. Build against Beta 2 or later and the binary loads on 22.0 gold.

Not covered

Video, music, texture and add-on database schema versions are internal to an installation and are not part of this schedule.

02What moves when

From this cutMajorMinorPatchWhat may still land
Alpha openopenopen Anything, including breaking changes
Beta 1 lockedopenopen Additive API only. No signature, semantic or floor change
RC1 lockedlockedopen Fixes to declared behaviour. No new surface
Gold, point releases lockedlockedopen Fixes only, for the life of the branch

Locked means the component does not change, in either direction, for the rest of the release. A change that would move one waits for the next cycle’s alpha.

04Enforcement

Every version above is declared in api-versions.json, beside version.txt. CI validates each pull request against it.

{
  "release": { "major": 22, "codename": "Piers" },
  "surfaces": [
    {
      "id":       "jsonrpc",
      "path":     "xbmc/interfaces/json-rpc/schema/version.txt",
      "read":     "key:JSONRPC_VERSION",
      "line":     "14",
      "declared": "14.2.0"
    },
    {
      "id":       "python",
      "path":     "addons/xbmc.python/addon.xml",
      "read":     "xml:/addon/@version",
      "line":     "3",
      "declared": "3.1.0",
      "floor":    "3.0.0"
    },
    {
      "id":       "addon.game",
      "path":     "xbmc/addons/kodi-dev-kit/include/kodi/versions.h",
      "read":     "define:ADDON_INSTANCE_VERSION_GAME",
      "line":     "8",
      "declared": "8.0.0",
      "floor":    "8.0.0"
    }
  ]
}

The phase comes from VERSION_TAG. A pull request fails if a locked component or a floor differs from declared, if a major differs from line, or if a version goes backwards. declared is re-baselined on the cut commit and nowhere else.
